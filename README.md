# SciJava Incubator (retired)

This repository was a staging ground for fledgling SciJava projects
from 2020 to 2024. Every component that graduated now lives in
[scijava/scijava](https://github.com/scijava/scijava),
and this repository is archived.

* The principles first worked out here, including
  **incarnational versioning**, are now documented in
  [docs/versioning.md](https://github.com/scijava/scijava/blob/main/docs/versioning.md).
* The original README is in this repository's
  [history](https://github.com/scijava/incubator/blob/99712e0471d36339e84852871614a96380916364/README.md).

For support, please visit the [Image.sc Forum](https://forum.image.sc).
